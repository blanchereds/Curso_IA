# Instrucciones

1. Cree un fork de este repositorio
2. Clone el repositorio en su cuenta
3. En su copia, agregue una carpeta con su nombre (ejem: jose_luis_cruz)
4. Dentro de su carpeta, agregue un readme donde indique su nombre nombre completo y algo mas que guste probar con markdown.
5. Suba sus cambios a su repositorio remoto
6. Haga un pull request para que fusiones sus cambios en este repositorio
